# Today-I-Learned
TIL方式の学習記録リポジトリ

- 月刊学習：月間でその日学習したことを記録する
- ジャンル別まとめ：不定期にジャンルごとの学習のまとめを記録する

## 環境

- Github Actions
- Github Pages
- MkDocs
- Python 3.14.7

<br>

Github Actionsにて、CI/CDパイプラインを構築。

```
1. mainブランチに変更があると、MkDocs(Python)によりMarkdownがHTMLにビルド
2. Github Pagesにデプロイ
```
