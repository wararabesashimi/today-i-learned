リージョンはAWSがサービスを提供している国や拠点を指す。<br>
リージョン同士は地理的に離れた位置に存在する。

アベイラビリティゾーン(AZ)は複数のデータセンター(DC)から構成され、リージョンは複数のAZから構成される。<br>
> リージョン > AZ > DC

各AZ同士は地理的、電源的に独立した場所にあり、最低でも数十kmは離れているらしい。<br>
仮に災害等でAZの一つが使用不可になったとしても、リージョン内の他のAZでサービスを継続することができる。<br>
→ 高耐久性、高信頼性の担保

ただし当然ながらユーザー側が単一のAZにインスタンスを立てていた場合はオンプレとなんら変わりない。<br>
→ 冗長的な `マルチAZ` で高耐久性を確保する。
> AZ 1にインスタンス 1、AZ 2にインスタンス 2を立てて、DBをメインからサブへレプリケーションする等すると、異なるサーバーへのアクセスも同じDBのデータを返すことができる。

### 09-23
`git remote add <リモート名> <リモートリポジトリのリンク>` でorigin以外のリモートリポジトリを保持しておくことができる。<br>
→ リンクには `https` か `SSH` のものを貼り付ける。

pushする時には以下の様に追加したリモートリポジトリ名を指定する。
```
git push <リモート名> <ブランチ名>
```

余談だが、`git push` のように引数を省略した場合は、
```
git config --global push.default
```
で指定した設定でpushを行う。<br>
push.defaultの設定を変更したい場合は以下のコマンドで設定。
```
git config --global push.default simple
```
